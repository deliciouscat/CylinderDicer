# CylinderDicer

Lier’s Dice와 Russian Roulette를 조합한 게임.

## 프로젝트 구조

- Defold는 실제 게임 플레이 화면을 담당한다.
- 최종 배포는 HTML5/Web build를 Vue.js 애플리케이션에 임베드하는 방향이다.
- Vue는 로그인, 로비, 공방/래더 입장, 상점, 결제, 랭킹, 우편, 공지 같은 게임 외부 화면을 담당한다.
- Defold와 Vue는 `main/game_bridge.lua`를 통해 메시지를 주고받는 구조로 확장한다.
- 백엔드 연동 내용은 [`BACKND_INTEGRATION.md`](../shared/docs/BACKND_INTEGRATION.md)에 계속 정리한다.

- Perudo 식으로 숫자를 올리거나 결투를 신청
- 주사위를 줄이는 대신, 리볼버로 상대 생명력을 깎음
- 턴을 넘기면 리볼버에 총알을 채울 수 있다.
- 도전을 할 시, 차이가 나는 숫자 만큼 이전 턴 - 상대 턴 도전자가 방아쇠를 당김.
리볼버이므로 총알이 일부만 나가거나 안나갈 수도 있음
- 숫자를 정확히 맞춘 경우:
맞춘 당사자(이전 턴 유저;A)가 나머지 플레이어를 순서대로 지목, 방아쇠를 당기거나 회피.
나머지 플레이어(;B)는 응사하기/그냥 맞기 중 선택 가능
- A 탄 있음 / B 걍맞기: B에게 데미지 줌
- A 탄 있음 / B 응사: B에게 데미지 줌 + B 탄 있으면 총알낭비
- A 탄 없음 / B 걍맞기: 아무 일 안일어남.
- A 탄 없음 / B 응사: B가 탄 있으면 A가 1 데미지
- A 회피 / B 걍맞기: 아무 일 안일어남.
- A 회피 / B 응사: B 탄 있으면 총알낭비

## 게임 진행 순서

### 장전 규칙
- 게임 시작 시: 각자 실린더의 원하는 칸에 **총알 3발**을 채우고 시작한다.
- 게임은 **쉐이킹(shaking) 턴으로 시작**한다.
- 이후 매 쉐이킹 턴마다(최초 제외) **한 발씩 장전**한다.
- bidding 시(넘기기): **bidding한 사람만 한 발 장전**한다.
- **결투신청 시에는 장전하지 않는다.**

### 장전 화면 연출
- bidding 과정의 장전: 우하단에 늘 떠 있는 cylinder의 빈 슬롯에 그대로 장전한다. (별도 등장 연출 없음)
- 최초 장전 및 shaking 이후 장전: cylinder가 **화면 밖에서 안으로 등장**하고, 장전이 끝나면 **다시 원위치(화면 밖)로** 돌아간다.

### 라운드 흐름
1. (게임 시작) 각자 실린더의 원하는 칸에 총알 3발을 채운다.
2. 첫 턴 유저가 `bidding과 장전`을 수행한다.
3. 다음 유저가 `bidding과 장전` 또는 `결투신청`을 선택한다.
4. 위 과정을 순서대로 반복한다.
5. 누군가 `결투신청`을 하면 테이블 화면으로 내려가 모두의 눈금을 공개한다.
   - bidding한 눈금의 개수가 **부족/초과/정확히 일치**인지 확인한다.
   - 위의 데미지 정책에 따라 데미지를 집행한다.
6. 집행이 끝나면 **쉐이킹 턴**으로 넘어간다. (이후 다시 1번 라운드 흐름 반복)

# 인게임 화면들

## 쉐이킹

- 모바일: 좌우로 터치드래그 해서 흔들기
- 데스크탑: 스페이스 또는 스페이스바로 흔들기

## 내 턴일 때

모든 화면엔 직관적인 안내가 필요. default로 표시하고, 옵션에서 끌 수 있게

- 선택지:
중앙 화면에 `넘기기`, `결투신청` 버튼 있음.
넘기기 - 칸 숫자, 주사위 숫자.
             모바일: 레일을 ‘터치 드래그’해서 칸 숫자 넘기고, 터치 후 주사위 숫자 선택. 
                         주사위를 Cylindal하게 굴려 숫자 선택. (터치 드래그) 
             데스크탑: 레일을 ‘드래그’, ‘화살표’, ‘← → 키’ 또는 ‘스크롤’해서 숫자 넘김.
                         주사위를 Cylindal하게 굴려 숫자 선택. (스크롤, 드래그, 화살표, ← → 키)
결투신청 - 버튼형
- 결투 화면
뒤집힌 컵이 올라가면서 투명화
선택된 숫자 주사위가 갯수대로 크게 보이고, 각 플레이어 일러스트 위에 주사위 표시.

왼 전턴, 오른 현재턴(도전자) 일러스트 뜨면서, `철컥` , `탕` 이펙트/효과음으로 전투 애니메이션

퍼펙트 시:
왼 전턴(맞춘사람), 오른 나머지 일러스트 뜨면서, 전투 애니메이션

## 상대 턴일 때

- 내 주사위 패 일렬로 보여줌
- 상대 일러스트
모바일: 현재턴 메인, 전턴 작게, 나머지 nail
데스크탑: 일렬배치 - carousel. 현턴 크게, 나머지 보통사이즈, 현전턴 제외 gray.
